# Math Teacher Game

A standalone browser game where you solve addition, subtraction, multiplication, and division questions.

## Run locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. GitHub will show the website URL in Settings → Pages.

The game is self-contained: the teacher avatar is embedded in `index.html`, so no separate image assets are required.
